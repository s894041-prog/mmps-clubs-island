# 馬鳴國小社團群島｜115 學年度天空之城 3D 社團探索互動網

本專案參考「南大附中探索群島」互動設計概念，以 **「天空之城（Laputa 雲海浮空島）」** 為視覺主題，結合溫暖手作質感的 3D 微縮模型風格，為 **臺中市外埔區馬鳴國民小學** 打造學生社團即時資訊互動網站。

## 🌐 線上展示與開啟方式
* **線上體驗（GitHub Pages）**：https://s894041-prog.github.io/mmps-clubs-island/
* **直接本機雙擊開啟**：本機點擊 [`index.html`](./index.html) 即可離線流暢執行（內建 Three.js）。

## 🎮 自由漫遊奔跑模式 (RPG Third-Person Controller)
點擊底部工具列綠色的 **「🎮 自由漫遊」** 按鈕，即可生成一位背著黃色小書包的馬鳴小學生，親自在雲海浮空島與空橋上奔跑探索：
* **前進／後退／轉向**：鍵盤 `W` `A` `S` `D` 或 `↑` `↓` `←` `→`
* **跳躍**：`Space` 空白鍵
* **衝刺跑步**：`Shift` 鍵
* **空橋穿梭**：可直接踩著木質拱形雲海空橋，一路從中央主島跑向 8 座社團島！
* **走近觸發**：跑到任何一座社團島（如踏入 DOC 智高社或操場獨輪車社），畫面頂部會顯示提示，按 `E` 鍵或點擊即可開啟社團介紹。
* **手機支援**：行動裝置會自動彈出螢幕**虛擬方向鍵**與**跳躍按鈕**。

## ✨ 核心互動功能
- **🏰 天空之城 3D 浮空群島**：每座小島底部皆有錐形浮空岩層、發光飛行石能量核心與托島雲朵，四周環繞立體雲海、復古飛空艇與彩色熱氣球。
- **⚡ 即時雷達 & 時段模擬器**：切換時段即時亮起「LIVE 上課中」動態光環。
- **🗺️ 校園平面圖雙向定位**：整合 `馬鳴平面.jpg`，標註所有社團教室座標與走法路線。
- **📝 數位報名回條**：依年級自動過濾資格、防衝堂警示並可一鍵列印紙本。
- **🦄 9 隻馬鳴小天馬尋寶彩蛋**：點擊小天馬會高興跳起旋轉。
