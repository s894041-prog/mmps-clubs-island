# 馬鳴國小社團群島｜115 學年度天空之城 3D 社團探索互動網

本專案參考「南大附中探索群島」互動設計概念，以 **「天空之城（Laputa 雲海浮空島）」** 為視覺主題，結合溫暖手作質感的 3D 微縮模型風格，為 **臺中市外埔區馬鳴國民小學** 打造學生社團即時資訊互動網站。

## 🚀 開啟方式
1. **直接雙擊開啟（免伺服器）**：直接點擊資料夾內的 [`index.html`](./index.html) 即可於瀏覽器流暢執行（已內建本地 `three.min.js`，支援離線與 `file://` 直接開啟）。
2. **部署上網**：可將本資料夾直接拖曳部署至 Vercel、Netlify 或 GitHub Pages。

## ✨ 核心互動功能
- **🏰 天空之城 3D 浮空群島**：每座小島底部皆有錐形浮空岩層、發光飛行石能量核心與托島雲朵，四周環繞多層立體雲海、復古飛空艇與彩色熱氣球。
- **🎭 社團微縮模型與動態小人**：操場上騎獨輪車繞圈、校長書法巡堂與懸空巨型毛筆、太鼓擊鼓律動、節奏樂木琴合奏與漂浮音符、梅花樁醒獅跳躍、旋轉地球儀與 ABC 積木、DOC 教室動態咬合智高齒輪組與機械手臂。
- **⚡ 馬鳴社團即時雷達 & 時段模擬器**：可一鍵切換各星期上課時段，對應浮空島立即點亮「LIVE 上課中」動態光環。
- **🗺️ 校園平面圖雙向定位**：整合 `馬鳴平面.jpg`，標註所有社團上課教室座標與動線指引，點擊平面圖座標即可飛往該座 3D 浮空島。
- **📝 數位報名回條試算與衝堂檢查**：依年級自動過濾可選社團、主動提示週三下午重疊或無縫接軌時段，支援一鍵列印紙本回條。
- **✈️ 自動巡航導覽 ＆ ✨ 社團適性小測驗 ＆ 🦄 9 隻馬鳴小天馬尋寶彩蛋**。
