## ✨ 核心功能亮點

1. **雙模式無痛中打體驗**：
   - **🎯 注音按鍵導引模式（預設，免切輸入法直通車）**：自動將每個國字拆解為「聲母 ➔ 介音 ➔ 韻母 ➔ 聲調鍵」並同步點亮畫面下方的十指虛擬鍵盤，就算電腦目前在英文輸入法狀態也能直接練習注音鍵位！
